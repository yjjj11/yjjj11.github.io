## 项目简介

一个本地部署的批量评论审核系统：用**两级检测架构**做电商评论的自动审核，覆盖辱骂内容、广告引流、虚假刷单、事实核查四类任务。一审小模型快速过滤，二审大模型 Agent 复核，**单条评论平均 0.03 秒，批量吞吐约 120 条/秒**。

## 两级检测架构

- **一审（快）**：四个模型并行检测，Qwen2.5-0.5B + LoRA 微调（本地 vLLM 部署），0.03s 平均耗时
- **二审（准）**：大模型 Agent + 联网搜索，对存疑内容复核；结果自动回流入训练数据，实现"自主学习闭环"

## 核心特性

- **多模态支持**：文本 + 多张图片并行审核（二维码/联系方式/低俗色情/广告引流），图片违规优先拦截
- **RAG 检索增强**：BGE-m3 嵌入 + Milvus 向量库，Multi-Query + HyDE 双优化 + RRF 融合
- **LoRA 高效微调**：四任务合一微调框架，只训练少量参数
- **零依赖部署**：默认 Milvus Lite 本地文件模式，无需 Docker
- **前后端分离**：FastAPI + 原生前端，一键启动

## 收获

一个项目把大模型应用开发的主线全走了一遍：小模型微调（LoRA）、vLLM 高并发推理、Agent 工具调用、RAG 检索增强、多模态检测、数据闭环迭代。单条评论从 4s 优化到 0.03s（133 倍提升）的过程，对性能优化和系统设计很有启发。
