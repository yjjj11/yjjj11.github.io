## 项目简介

一个手写的 JSON 解析器，把 JSON 文本解析成内存里的数据结构，也支持反向序列化。JSON 是前后端通信最常用的数据格式，自己写一遍解析器，才能真正理解它背后的规则和实现思路。

## 涉及要点

- 词法分析：把字符串拆成 token（`{`、`}`、`[`、`]`、字符串、数字等）
- 递归下降解析：按 JSON 语法逐层解析成嵌套结构
- 类型处理：对象、数组、字符串、数字、布尔、null
