## 项目简介

一个基于 Kafka 的订单日志收集与处理系统练习。消息队列是分布式系统解耦、削峰、异步化的核心组件，Kafka 作为其中的代表，是后端开发必须掌握的中间件。

## 涉及内容

- Kafka 的 topic / partition / consumer group 模型
- 生产者和消费者的 API 使用
- 订单日志的写入、流转与消费
- 消息的可靠性与有序性处理

## 收获

通过一个具体业务场景（订单日志）把 Kafka 的常用功能串起来，比单纯看文档理解深刻得多。
