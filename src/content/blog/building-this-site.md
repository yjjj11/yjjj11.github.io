> 这篇是本站的"开站文"，记录这个小站从 0 到 1 是怎么搭起来的，以及每一步做选择时是怎么想的。

## 为什么要建站

学编程学了这么久，知识都散落在各个仓库和笔记里，没有一个能对外展示的地方。建一个自己的博客，既是对学习历程的记录，也是一个"作品集"——让访问者能看到我做过哪些项目、踩过哪些坑。

## 技术选型：为什么是 Astro

建站第一步是选技术栈，我主要考虑了三个方向：

1. **传统框架（React / Vue）**：功能强，但对一个个人博客来说太重，还要维护一套前端工程。
2. **Hexo / Hugo**：经典博客框架，上手快，但定制起来相对受限。
3. **Astro**：最终选择。理由很实在：
   - **纯静态输出**：构建后就是一堆 HTML/CSS/JS，不需要服务器、不需要数据库
   - **内容集合（Content Collections）**：用 Markdown 写文章，配合 schema 校验，还能一个集合装文章、一个装项目、一个装问题记录
   - **默认零 JS**：页面打开快，SEO 友好
   - **不用任何前端框架**：保持简单，把精力放在内容上

所以这个站从头到尾**没有用 Vue**，也没有点赞按钮之类花哨的东西——就一个朴素的静态站。

## 视觉设计：深色终端风

设计上我参考了一个我很喜欢的站（dev.styunlen.cn），复刻了它的**深色终端风格**：

- 深色背景 + 黄色高亮（`#e3b341`）+ 等宽字体，像敲代码一样的感觉
- 用 `>_` 作为 logo 的前缀，呼应终端提示符
- 后来迭代出的几个特色：
  - **大屏欢迎页**：进入网站先看到一行炫酷的欢迎语，按任意键进入首页
  - **项目难度星级**：左侧目录每个项目旁边用 1~5 星标注难度，从简单到难排好，方便访问者挑选
  - **搜索 + 标签筛选**：项目列表支持按关键词搜索，也可以点分类标签（分布式 / C++ / 网络编程 / 数据库 / AI Agent / IO）直接筛选

## 浏览量统计：不蒜子

博客得有浏览量才有"被看到"的感觉。选择**不蒜子（busuanzi）**的原因：

- **免费**，不用注册、不用申请 key
- **无后端**：它靠一段前端脚本自己计数，我只需要在页面上放一行脚本
- 支持站点总浏览量和单篇文章浏览量

> 小坑：本地 localhost 预览时计数是异常的，部署到公网域名后才正常。

## 部署：GitHub Pages + GitHub Actions

托管平台对比了一圈，选了 **GitHub Pages**：

- **完全免费**，不限制流量
- 和代码仓库天然一体：推代码到 `main` 分支，**GitHub Actions 自动执行 `npm run build` 再发布**，改完文章 `git push` 一下，几十秒网站就更新了
- 支持自定义域名

整个流程就是：**本地写 Markdown → git commit → git push → 网站自动更新**，完全不用碰服务器。

## 内容架构：三个内容集合

用 Astro 的内容集合拆成了三类，各有各的页面：

| 集合 | 内容 | 页面 |
|------|------|------|
| `blog` | 文章 | `/blog/` |
| `projects` | 项目（含难度星级、技术标签） | `/projects/` |
| `solutions` | 踩坑与问题解决记录 | `/solutions/` |

项目和问题解决页都用了"左侧目录 + 右侧详情"的排版，方便浏览。

## 收获

一次完整的建站，其实把 Web 开发的整个链路都走了一遍：技术选型、静态站构建、内容管理、视觉设计、统计埋点、CI/CD 自动部署。很多东西在文档里看一百遍，不如自己搭一个站来得深刻。
