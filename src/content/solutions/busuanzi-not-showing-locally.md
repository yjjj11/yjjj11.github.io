## 问题现象

在博客里接入了不蒜子（busuanzi）访问统计，但本地 `npm run dev` 预览时，浏览量一直显示 0 或者异常大的数字，看不到真实数据。

## 原因

不蒜子是**按访问者的域名来计数**的。它只认公网真实网址，`localhost`（本地）不在它的统计范围内——所以本地预览时计数自然不对，这不是代码写错了。

## 解决办法

1. **不用管它**：本地预览阶段浏览量数据没有意义，直接忽略即可
2. **部署到公网**：把网站部署到 GitHub Pages / Netlify 等有真实网址的地方后，浏览量就会正常显示和累计
3. 另外注意：列表页（比如 `/blog/`）不会显示逐篇浏览量，只有文章详情页有 `busuanzi_page_pv`；站点总浏览量在侧边栏的 `busuanzi_site_pv`

## 经验总结

- 第三方统计工具大多只认公网域名，本地测试数据不可信
- 判断统计是否接入成功，部署上线后看数字涨没涨就知道了
